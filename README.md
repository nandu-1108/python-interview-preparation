# My Memory – Interview Preparation System

## 📌 About the Project

**My Memory** is a Python-based interview preparation application designed to help users organize technical concepts, save interview questions, and practice for interviews.

The application provides a structured way to store learning notes and interview information using a graphical user interface built with Tkinter and a MySQL database.

## ✨ Features

- **Subject Management** – Organize subjects for learning and revision.
- **Topic Management** – Store technical definitions and personal explanations.
- **Company Management** – Save company names and locations.
- **Interview Management** – Record job roles, interview dates, and interview rounds.
- **Interview Questions** – Store questions for interview preparation.
- **Practice Mode** – Practice previously saved interview questions.
- **MySQL Database** – Store information persistently.
- **Tkinter GUI** – Interact with the application through a desktop interface.

## 🛠️ Technologies Used

- **Python** – Application logic
- **Tkinter** – Graphical user interface
- **MySQL** – Database management
- **MySQL Connector/Python** – Python–MySQL connectivity

## ⚙️ Requirements

- Python 3.x
- MySQL Server
- MySQL Workbench (optional, for database management)
- Required Python packages

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/my-memory-interview-prep.git
```

### 2. Navigate to the Project Folder

```bash
cd my-memory-interview-prep
```

### 3. Install the MySQL Connector

```bash
pip install mysql-connector-python
```

### 4. Configure the Database

Create the `my_memory` database in MySQL and configure the database connection details in the Python application.

Ensure the required tables are created before running the application.

### 5. Run the Application

```bash
python My_Memory_Complete_Improved.py
```

*Note: Update the filename in this command if your main Python file has a different name.*
